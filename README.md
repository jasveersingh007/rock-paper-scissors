
# Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game developed using Python.

## Technologies Used
- Python
- Random module
- Conditional statements

## Features
- Allows users to choose Rock, Paper or Scissors.
- Generates a random choice for the computer.
- Determines the winner based on the game rules.
- Displays the result.

## How to Run
1. Install Python.
2. Download the repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python main.py
```

- Practised Python fundamentals.
- Improved understanding of conditional statements.
- Learned to use Python's random module.
- Developed a basic interactive game.
